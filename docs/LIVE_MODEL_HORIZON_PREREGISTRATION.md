# Live-Model Horizon Evaluation Preregistration

**Status:** Preregistered design; no live results collected
**Preregistration date:** 2026-09-04
**Synthetic baseline:** [frozen separately](HORIZON_AWARE_SYNTHETIC_FREEZE.md)

## Purpose

This phase observes whether the containment behavior seen in the deterministic
synthetic harness persists when trajectories are generated by a locally hosted
model through an explicitly enabled LM Studio adapter. It is observational and
advisory only. The adapter does not change authoritative governance.

The preregistered questions are:

1. Does Agent K reduce unsafe persistence relative to an ungoverned baseline as trajectory horizon increases?
2. Does the semantic judge add useful detection coverage without weakening deterministic containment?

`D > C` is not assumed. `C approximately equals D`, `D > C`, and `D < C` are all
valid possible outcomes.

## Conditions and horizons

The matched conditions remain:

- **A:** baseline, no intermediate evaluation;
- **B:** LLM semantic judge only;
- **C:** Agent K deterministic evaluation only;
- **D:** Agent K plus bounded LLM semantic judge.

Horizon values remain `2, 4, 8, 16, 32`, subject to operational feasibility.
Pilot trajectories are adapter/instrumentation checks only and are excluded from
all preregistered estimates.

## Governance boundary

Agent K remains authoritative for schemas, invariants, preconditions, state
transitions, tool contracts, deterministic policy, and hard failures. The LLM
judge may assess semantic nuance, ambiguity, and semantic consistency only. It
cannot create evidence or provenance, widen authority, approve an action,
convert a hard Agent K failure into a pass, or modify confidence by itself.

Malformed JSON, missing fields, refusal, disagreement, timeout, and unavailable
LM Studio endpoint are explicit observed outcomes. They fail closed and are not
silently retried or fabricated into valid judgments.

## Per-trajectory record

Each trajectory records the complete ordered trace and raw model outputs,
including:

- trajectory, task, seed, horizon, condition, and pilot/experimental status;
- model identity, LM Studio endpoint label, model configuration, temperature,
sampling parameters, adapter version, and prompt/config fingerprints;
- first-error position and error class;
- detected versus undetected fault;
- Agent K decision and semantic-judge decision;
- containment, propagation, unsafe persistence, safe termination, safe
continuation, and safe recovery;
- final task outcome;
- request/response timing, timeout/refusal/unavailable status, validation errors,
and trace integrity metadata.

Raw model output is preserved as an audit artifact. Secrets and unrelated local
content must not be included in traces.

## Metrics and analysis

Keep the synthetic definitions unchanged. Report by horizon and condition:

- task success;
- first-error containment;
- propagation suppression;
- unsafe persistence;
- safe recovery conditional on detected fault;
- post-fault outcomes;
- semantic-judge detection coverage and disagreement with Agent K;
- timeout, malformed, refusal, and endpoint-unavailable rates.

Report Wilson 95% intervals where denominators support them and report
not-estimable metrics explicitly. Separate pilot diagnostics from experimental
results. Compare C and D descriptively without assuming direction. No aggregate
completion improvement is sufficient to claim agent-rot mitigation.

## Pilot and stopping rules

Run only a small pilot first to validate adapter connectivity, schema parsing,
trace persistence, and fail-closed behavior. Pilot results cannot tune frozen
metrics, thresholds, prompts, or decision rules. Freeze the adapter version and
configuration after pilot validation before the experimental run.

Stop and mark the run invalid if a judge overrides a hard Agent K failure,
malformed output becomes accepted, raw output or trace cannot be reconstructed,
a timeout is silently converted to a result, or authority widens.

## Claim boundary

Until this phase is complete, the repository may claim only that the
deterministic synthetic harness demonstrates containment and safe-recovery
behavior under its programmed fault model. Live results are observational
evidence only and must not be described as proof that PRAETOR mitigates agent
rot, improves general LLM reliability, or increases task completion.
